# disktree interface language - English.
#
# The English text is the key: a line below is `text=text`, given so the
# key set is visible and the English wording can be changed without
# touching the code. Other languages are separate files,
# disktree.de.i18n.txt and so on, looked up beside the executable, in the
# working directory, then under %APPDATA%\disktree (~/.config/disktree).
# A key that itself contains `=` uses a TAB between key and text.
# A key no file defines is shown as it is, so a partly filled file is safe.
