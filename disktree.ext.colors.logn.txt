# disktree file-type colours - a thorough example.
#
# Copy this file to `disktree.ext.colors.txt` (or rename it) and switch on
# "File type colors" in the legend row. It is looked up beside the
# executable, in the working directory, then under %APPDATA%\disktree
# (~/.config/disktree).
#
# One `extension=#rrggbb` per line. A line starting with `#` is a comment,
# blank lines are skipped, and the extension is matched without case and
# without the dot. A file whose type is not listed keeps its category colour.
#
# Colours below are grouped by kind: images are amber, music green, video
# violet, text blue, web and code cyan, office rose, archives yellow, fonts
# magenta, executables slate, databases olive, games indigo.
